## 🧠 Overview

This is a **console-based Student Information System** developed in C++.

It simulates a real academic management system used in universities to:
- Manage students
- Manage courses
- Handle grades and GPA calculation

The project focuses on **input validation, structured programming, and real-world system design**.

---

## 🚀 Features

### 👨‍🎓 Student Management
- Add new student with full validation:
  - Full name (first + last name)
  - National ID (14 digits, no leading zero)
  - Gender (M/F)
  - Date of Birth (DD/MM/YYYY + age check)
  - Phone number (11 digits starting with 01)
  - Program selection (CSE / CCE / MCT)
  - Academic level (1–4)

- Future options (menu included):
  - Search student
  - Update student
  - Delete student
  - List all students

---

### 📘 Course Management
- Add new course
- View all courses
- Update course
- Delete course

---

### 📊 Grades Management
- Enter student grades
- View grades
- Calculate GPA
- Generate transcript
