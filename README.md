## 🧠 Overview

This project is a **complete console-based Student Information System** developed using C++.

It simulates a real university management system that allows administrators to manage:

* Students
* Courses
* Grades and transcripts

The system was designed with a strong focus on:

* Data validation
* File handling and persistence
* Modular programming
* Real-world academic workflow simulation

---

## 🚀 Features

### 👨‍🎓 Student Management

* Add new students with full input validation:

  * Full name validation
  * National ID validation (14 digits)
  * Gender selection
  * Date of birth and age verification
  * Phone number validation
  * Program selection (CSE / CCE / MCT)
  * Academic level validation

* Search for students

* Update student information

* Delete students

* Display all students

---

### 📘 Course Management

* Add new courses
* Update course information
* Delete courses
* Display all available courses

---

### 📊 Grades & GPA Management

* Assign grades to students
* View student grades
* GPA calculation system
* Generate student transcripts
* Course-hour based GPA processing

---

## 💾 Data Persistence

* File handling using:

  * `ifstream`
  * `ofstream`

* Automatic loading and saving of:

  * Students
  * Courses
  * Grades
